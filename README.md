# BookCatalog
Лабораторная работа №4 по дисциплине «Инструментальные средства разработки программного обеспечения».

## Тема
Разработка и интеграция модулей проекта. Отладка отдельных модулей. Организация обработки исключений.

## Структура решения
BookCatalog — библиотека классов:
 - `Models` — сущности (`Book`).
 - `Services` — реализация интерфейса `BookServise`.
 - `Contracts` — интерфейс `IBookService`.
 - `Exceptions` — собственные исключения (`BookNotFoundException`, `InvalidParameterException`).
	
 BookTest — проект модульных тестов.

 ## Запуск тестов
1. Открыть решение `BankLibrary.slnx` в Visual Studio 2022.
2. Меню **Тест** → **Запустить все тесты**.
3. Ожидаемый результат: 2 из 3 тестов пройдены.
